# Single-Phase Grid-Connected Solar PV System

## Overview
A MATLAB/Simulink project that simulates a single-phase solar photovoltaic (PV) system connected to the utility grid. The system uses Maximum Power Point Tracking (MPPT) to extract maximum power from the PV array and a current controller to regulate power injection into the grid.

## Features
- Solar PV plant modelling under varying irradiance conditions.
- MPPT using Perturbation and Observation (P&O) or Incremental Conductance.
- Grid synchronisation using a Phase-Locked Loop (PLL).
- Current control for grid-connected operation.
- Inductor-based output filtering.
- Grid protection and circuit-breaker control.
- Monitoring of PV voltage, PV current, grid current, and power.
- Control-system linearization and frequency-response analysis.
